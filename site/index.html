Targeted Reporting Architecture

One Audit Engine, Two Tailored Audiences

Complex audits fail when technical jargon overwhelms business owners or high-level summaries omit actionable code context. SiteIntel Pulse bridges this gap with dual projections.

Company A — Website Owner

Executive Owner Report

Designed for founders, CMOs, and e-commerce managers. Translates raw crawler evidence into high-level opportunity themes, risk indicators, and strategic roadmaps.

  • 13 Visual Dashboard Cards: High-level cards covering SEO, Performance, Security, Accessibility, and AI-search readiness.
  • Explicit Provenance Scoring: Distinguishes earned points, tested points, and category coverage percentages.
  • Strategic Opportunity Plan: Prioritizes high-ROI growth fixes without confusing technical jargon.
  • Executive PDF Generator: High-fidelity downloadable A4 PDF reports via Playwright Chromium.

Deterministic Scoring Engine

The 56-Rule Assessment Catalogue

SiteIntel Pulse evaluates websites across 11 canonical categories totaling exactly 100 points. All rules are deterministic, versioned, and evaluated against verifiable public evidence.

ID Category Name Weight Rules Description & Scope
CAT-01 Technical Health and Crawlability 12 pts 6 tests HTTPS entry availability, redirects, canonical consistency, robots.txt, sitemap parsing, internal broken links.
CAT-02 Technical and On-Page SEO 18 pts 9 tests Title/meta tag presence, heading hierarchies, URL slugs, image alt attributes, structured data (JSON-LD), link hygiene.
CAT-03 Performance 10 pts 5 tests PageSpeed lab scores, Core Web Vitals (LCP, INP, CLS field data), render-blocking resources, asset payload weight.
CAT-04 Responsive Experience & Accessibility 10 pts 5 tests Viewport configuration, horizontal scroll overflow across 7 device viewports (320–1440px), touch targets, basic a11y.
CAT-05 Public Security Configuration 12 pts 6 tests TLS certificate observations, security headers (HSTS, CSP, X-Frame-Options), mixed content, cookie security flags.
CAT-06 Observable Authentication Posture 8 pts 4 tests Public login/signup surfaces, form transport security, session security attributes, visible MFA/SSO evidence.
CAT-07 Content Quality and Trust 10 pts 5 tests Value proposition clarity, readability chunking, ownership/contact signals, resource/blog availability, thin content.
CAT-08 GEO / AEO and AI-Search Readiness 8 pts 4 tests AI crawler bot access policy (GPTBot, ClaudeBot), main-text crawlability, structured entity schemas, answer-ready content.
CAT-09 Analytics and Tracking Readiness 5 pts 5 tests GA4 measurement tags, Google Tag Manager container, marketing pixels, cookie consent UI, account connection status.
CAT-10 Conversion and Marketing Experience 4 pts 4 tests Above-the-fold value proposition CTA, navigation pathways to checkout/inquiry, form usability, policy transparency.
CAT-11 Competitive Comparison Readiness 3 pts 3 tests Comparator domain definition, comparable public technical health metrics, external market data provenance.
TOTAL Complete Scoring Catalogue 100 pts 56 rules Standardized 100-point composite assessment baseline.
Defense-in-Depth Engineering

Architecture & Security Safeguards

SiteIntel Pulse is engineered to guarantee zero unauthorized scanning exposure, safe data handling, and reliable durability.

SSRF & Crawler Defense Gate

Before initiating any HTTP request, the crawler validates target domains via DNS resolution, rejecting loopback, RFC 1918 private ranges, and cloud metadata endpoints (e.g. 169.254.169.254).

  • 50 page default budget (hard limit 100)
  • 2 MiB per-page decompression limit
  • 50 MiB total scan cap
  • Respects robots.txt directives & bot policy

Multi-Tenant & Persistence Security

Native SQLite persistence running in WAL mode with relational foreign keys. Enforces strict tenant boundaries across all 15 API routes.

  • OWASP 220,000 iterations PBKDF2 hashing
  • Durable login rate limiter (prevents DoS lockouts)
  • Online hot backup snapshot via VACUUM INTO
  • Production demo seed lockouts

Core Technology Stack

Next.js 15.1.7 (App Router) React 19 TypeScript 5.7 Tailwind CSS 3.4 Node.js 22 (node:sqlite) Playwright Chromium Vitest 3.0
